# Sổ TPCN gia đình

App một file (`index.html`), không cần cài đặt. Mở bằng trình duyệt, hoặc `npx serve tpcn`.
Dữ liệu lưu trong IndexedDB của trình duyệt; sao lưu bằng nút "Tải JSON".

- Gia đình, sản phẩm, lượt uống (đang uống / đã uống), ghi chú kiến thức
- Nhập từ link (trích văn bản) và ảnh (OCR vie+ces+eng bằng Tesseract.js, cần internet lần đầu)
- Xuất JSON / CSV, in báo cáo theo từng người
