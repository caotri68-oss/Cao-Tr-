# Đột Kích Hoàng Hôn

Game bắn súng đi cảnh (side-scroller) đơn giản, chạy trong trình duyệt, tối ưu cho điện thoại Android.
Một file duy nhất: `index.html` — không cần cài đặt, không cần build.

## Cách chơi trên Android
1. Mở `index.html` bằng Chrome (qua GitHub Pages, máy chủ bất kỳ, hoặc file trên máy).
2. Menu ⋮ → **Thêm vào màn hình chính** để mở như một ứng dụng.
3. Xoay ngang điện thoại để nhìn xa hơn.

## Điều khiển
| Cảm ứng | Bàn phím | Tác dụng |
|---|---|---|
| ◀ ▶ (góc trái, có thể kéo ngón tay) | ← → / A D | Chạy |
| NHẢY | Space / Z / ↑ | Nhảy (giữ lâu nhảy cao hơn) |
| BẮN (giữ) | X / J | Bắn liên tục |
| II | P / Esc | Tạm dừng |

## Luật
- 5 máu. Trúng đạn, chạm địch hoặc rơi xuống hố: mất 1 máu.
- Lính: 100 điểm · Drone: 150 · Tháp pháo (từ màn 2): 300.
- Chạm lá cờ cuối màn để qua màn (+500 điểm + 100/máu còn lại, hồi 1 máu).
- Vật phẩm: ❤ hồi 1 máu · ô **S** = súng 3 tia trong 12 giây.
- Màn sau dài hơn, địch đông hơn và bắn nhanh hơn. Kỷ lục lưu trên máy.
